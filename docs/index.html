🗓 Timesag

A modern, calendar-style weekly timesheet for the desktop.

What it does

Each weekday is a vertical time axis you fill with colour-coded boxes — working, holiday, sick, paid time off or bank holiday. Timesag writes them out in the exact fixed-width format the payroll system expects, one line per box.

🧱 Duration boxes

Boxes auto-stack from a start time; height is proportional to hours. Minimum 0.5 h so controls always fit.

✏️ Edit in place

Type, hours and project live inside each box. Change hours and the box resizes on the timeline.

🕗 Draggable start

Drag a box to move the day's start (snaps to half-hours); double-click to reset to 08:00.

🎯 Total badge

A colour-coded pill shows the day's summed hours against a 7.4 h target.

🌍 Special days

World, Danish, Spanish, British and Indian observances, each with a hand-drawn flag.

📋 Save & Copy

Write the week to Timesag/<week>_oat.txt or copy the lines to the clipboard. The web version copies only — it keeps the week in your browser instead.

Inclusive on-this-day selection

Every column shows a clickable Wikipedia fact for that date, from the free Wikimedia “On This Day” feed. The item is chosen by a process designed to surface real history and under-represented figures:

  1. Score every candidate. Events, births and deaths are scored, with a boost for discovery/science and notable-figure keywords.
  2. Default to an event or discovery. The best historical event wins by default — so discoveries keep appearing, and famous figures still show through events about them (e.g. “Einstein sends the special-relativity paper”).
  3. Inclusive boost — up to a 50% chance. Among the day's top people, Timesag reads Wikidata claims P21 (sex/gender ≠ male → women, non-binary) and P91 (recorded sexual orientation → LGBTQ+). If one exists, a coin flip features them instead of the default event.

Why not ethnic group? Wikidata's P172 is filled for almost every notable figure (Newton, Einstein included), so its presence is no signal of a minority and would flag nearly everyone — defeating the 50% balance. It is deliberately not used; boosting specific ethnic minorities would need a curated list.

Get started

git clone https://github.com/oateiva/OATimesag.git
cd OATimesag
pip install -r requirements.txt
python timesag.py

Working-day projects live in projects.json; special days in observances.json (auto-seeded, editable).

Output format

One line per box: 110000,DD-MM-YYYY,0,R,0,<code>,<hours>,T,<f9>,,<description>
